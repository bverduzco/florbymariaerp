How It Works
Every write operation (create, update, delete) in the ERP automatically creates an audit log entry. The entry records: timestamp, who performed the action (user name or 'System' for auto-generated entries), the action type (CREATE/UPDATE/DELETE), which table was affected, the record ID, which field changed (for updates), the old value and new value, and the source (which UI button or API call triggered it).
📝 Auto-generated entries: Stock Movements created from Ad-hoc Purchases, Loss entries from Reset Perishable Stock, Customer status changes from Quote status changes, Supplier Prices from Price List Update button — all logged automatically with source = 'Auto'.
🔍 The audit log is append-only — entries cannot be edited or deleted. It's the definitive record of everything that happened in the system, useful for compliance, dispute resolution, and debugging.
